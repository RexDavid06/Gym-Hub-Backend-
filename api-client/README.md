# @gym-hub/api-client

Typed API client for Gym Hub web and mobile, generated from the backend OpenAPI schema.

## Layout

- `schema.yml` — canonical copy of the backend `schema.yml`. The backend is the source of truth.
- `src/schema.d.ts` — generated by `openapi-typescript`; do not edit by hand.
- `src/client.ts` — `createApiClient`, typed `apiFetch` / `buildApiPath`, and `ApiError`.
- `src/types.ts` — shared schema-derived type aliases.
- `src/index.ts` — public exports.

## Generate the schema types

Copy the regenerated backend schema over `schema.yml`, then run:

```sh
npm install
npm run gen:api
```

## Build

```sh
npm run typecheck
npm run test
npm run build
```

`dist/` is not committed. Consumers that depend on this package through `file:` need it built before
their typecheck, tests, or build run. Each consuming app's CI stages and builds the package first.

## Usage

```ts
import { createApiClient, ApiError } from '@gym-hub/api-client'

const client = createApiClient({
  baseUrl: 'http://127.0.0.1:8000',
  getAccessToken: () => accessToken,
  refreshAccessToken: async () => freshAccessToken,
})

const me = await client.apiFetch('/api/me/', 'get')
const users = await client.apiFetch('/api/users/', 'get', { query: { role: 'member' } })
```

The package never reads environment variables and never stores tokens. Host apps supply the base URL
and token accessors.
